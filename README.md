# Mini Task 1 - PowerShell Command

Membuat folder baru bernama "folderMusik" dengan command **mkdir** (*make directory*)
```sh
mkdir folderMusik
```

Pindah ke folder "folderMusik" dengan command **cd** (*change directory*)
```sh
cd folderMusik
```
